# Overview

I am building a small public software portfolio so I can practice publishing working code, clear documentation, and a short demo the same way a software engineer shares learning projects.

This program prints a single greeting to the terminal. It is a first published piece of software: a complete path from source file to a public repository.

I created it to confirm my local Python setup, practice GitHub from Visual Studio Code, and document the result so the next projects in my portfolio follow the same pattern.

[Software Demo Video](https://www.youtube.com/watch?v=NeRClqeS3n0)
